## Project Overview

This project delivers a structured analysis of an IT service desk operation, identifying process inefficiencies and proposing a data-driven improvement plan. Using real incident data from 20 logged tickets, the project measures SLA performance, maps current and future state workflows, and produces a formal improvement report with a 12-week implementation roadmap.

The project demonstrates skills directly applicable to IT Infrastructure Support, Cloud Support, and Technology Business Analyst roles — combining analytical thinking, process design, technical documentation, and ITIL-aligned service management principles.

---

## Key Finding

Out of 20 incidents analysed, 11 (55%) breached their SLA targets. The overall SLA compliance rate of 45% is significantly below the industry benchmark of 85-90%. Root cause analysis identified five systemic process failures responsible for 80% of all breaches.

## The 5 Process Improvements

| Initiative | Problem Solved | Expected Outcome |
|---|---|---|
| Self-Service Portal and Knowledge Base | All tickets routed through Tier 1 regardless of complexity | 25% reduction in ticket volume |
| Automated Priority Assignment | Manual misclassification of urgency | High priority breach rate drops from 67% to under 30% |
| SLA-Triggered Automatic Escalation | Email escalation caused delays and lost tickets | Escalation delay reduces from 4 hours to under 30 minutes |
| Known Error Database | Recurring issues resolved from scratch every time | Repeat incident resolution time reduced by 40% |
| Automated User Provisioning | Manual access requests taking 30+ hours | Access tickets resolved within 2 hours |
