# IT Service Desk Process Improvement Project

## Overview
This project analyses inefficiencies within a simulated IT service desk environment and proposes workflow improvements to enhance ticket management, escalation procedures, communication flow, and operational efficiency.

The project demonstrates analytical thinking, business process optimisation, technical documentation, and operational improvement skills relevant to business-focused technology environments.

---

## Objectives
- Identify inefficiencies within a traditional IT support workflow
- Improve ticket handling and escalation procedures
- Enhance communication between support teams and users
- Introduce SLA awareness and operational accountability
- Demonstrate business analysis and process optimisation principles

---

## Key Focus Areas
- Incident Management
- Ticket Prioritisation
- Escalation Workflows
- SLA Monitoring
- Process Optimisation
- Technical Documentation
